КАК ДОБАВИТЬ НОВОСТЬ НА САЙТ

Каждая новость — это два файла с ОДИНАКОВЫМ именем в папке posts:
  traxxas-txc-4m.txt   текст
  traxxas-txc-4m.jpg   фото (подойдёт и .png)

Имя файла станет адресом страницы, поэтому пишите его латиницей,
маленькими буквами, через дефис: brend-model.

ШАГ 1. ФОТО
  Назовите фото на компьютере так же, как будет называться новость.
  На GitHub откройте папку posts -> Add file -> Upload files ->
  перетащите фото -> Commit changes.

ШАГ 2. ТЕКСТ
  В папке posts нажмите Add file -> Create new file.
  В поле имени напишите то же имя с .txt на конце.
  Откройте файл _shablon.txt, скопируйте его содержимое, вставьте
  и замените на свой текст. Нажмите Commit changes.

Через 1-2 минуты новость появится на сайте: в ленте, в разделе,
на странице бренда и масштаба, в поиске, RSS и карте сайта.

ЧТО ПИСАТЬ В ШАПКЕ (всё, что выше строки ---)
  Название   полное название модели (обязательно)
  Раздел     машины, катера или самолёты (если не указать — машины)
  Масштаб    например 1:18 (можно не указывать)
  Статус     например: Анонс, В продаже, Предзаказ (можно не указывать)
  Дата       в виде 06.10.2026 (если не указать — сегодняшняя)
  Кратко     одно предложение для ленты
  Источник   ссылка, откуда взята новость (можно не указывать)
  Фото       чьё фото, например: Traxxas (если не указать — «производитель»)
  Бренд      нужен, только если бренд из двух слов: Cross RC, Hobby Plus

ПОСЛЕ СТРОКИ ---
  Первая строка — заголовок новости.
  Дальше абзацы текста через пустую строку.
  В конце можно добавить блок «Характеристики:» со списком через дефис.

КАК ИСПРАВИТЬ ИЛИ УДАЛИТЬ НОВОСТЬ
  Исправить: откройте её .txt файл на GitHub -> значок карандаша ->
  поправьте -> Commit changes.
  Удалить: откройте файл -> три точки справа вверху -> Delete file.
  Удалите и .txt, и фото.

НАСТРОЙКИ САЙТА
  Ссылка на Telegram, номер счётчика Метрики и коды подтверждения
  Яндекс Вебмастера и Google лежат в файле settings.txt.

ЕСЛИ НОВОСТЬ НЕ ПОЯВИЛАСЬ
  Проверьте: имена .txt и фото совпадают, в тексте есть строка ---,
  дата записана как 06.10.2026.
  На GitHub во вкладке Actions видно, прошла ли сборка: зелёная
  галочка — всё хорошо, красный крестик — что-то сломалось.

ОБЗОРЫ, СРАВНЕНИЯ И ТОПЫ (НЕСКОЛЬКО ФОТО)

Шаблон: posts/_shablon_obzor.txt

В шапке добавляется строка «Тип:» — обзор, сравнение или топ.
Такие материалы попадают в раздел «Обзоры и сравнения».
У сравнений и топов строку «Бренд:» можно не писать.
Источников может быть несколько: каждый на своей строке «Источник:».

Фото называются по номерам:
  obzor-traxxas-trx-4-ford-bronco-1.jpg   главное фото (обложка)
  obzor-traxxas-trx-4-ford-bronco-2.jpg   второе фото
  obzor-traxxas-trx-4-ford-bronco-3.jpg   и так далее

В тексте место для фото отмечается отдельной строкой: [фото 2]
Главное фото (-1) ставится наверх само, его отмечать не нужно.

Пока нет главного фото, статья на сайте не показывается.
Если нет фото 2 или 3, статья всё равно выйдет, просто без этого фото.

Подзаголовок: строка, которая начинается с ##
Таблица: строки, которые начинаются с вертикальной черты |
Строка, которая начинается с «Цена:», выделяется плашкой.
Строки, которые начинаются с //, на сайт не попадают.
